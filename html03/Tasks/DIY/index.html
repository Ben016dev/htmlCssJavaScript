Tags

Tags are used to write code, a few tags would be p, a, hx, body, footer, and strong. Tags have different uses for example the p, a, and hx tag store words. P stands for paragrapgh and is where a majority of written information would go. A is for anchor and is used to link parts of pages or other websites like this. Hx tags are for headings x can be 1-6 the larger the number the smaller the heading.

The body tag is where all the content of the page is put into, head is the tag where all the set up for the page goes. The footer is part of the body and as the tag implies is the bottom of the page, usually things such as copyright or a navigation bar are found there. The strong tag boldens a line of text the em tag puts that line into italics. Alternativley the b tag also boldens and the i tag also puts things into italics, however strong and em put emphasis on words when tts is used on the page.




Tips

Html is a simple coding language, however its still a coding language. There are a few things that someone would need to know before writing html beyond the tags, such as most tags need to be closed. Tags are typically surronded by these < >. For example the p tag would look like this < p > then when you are done writing in the paragraph you will ned to close the p tag with a similair one, except closing tags have a /, so closing a paragraph will look like this < / p >. Some tags such as br
the line break tag or the hr tag

which is similair but puts a line between, both are self closing do to not actually holding any content meaning they dont have nor need closing tags.
