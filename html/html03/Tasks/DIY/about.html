What is Html

Html is a coding langauge most commonly, and best used for website design. Html stands for Hypertext markup language. Typically Html wont be the only coding language used to make a website, but rather it acts as the base, like paper for an artwork. For example another common coding langauge that is used for website design is CSS or Cascading StyleSheets.

Origins of Html

Html originated in 1980, a physicist named Tim Bernes-Lee working at CERN proposed an internet based hypertext system. Tim wrote the browser and server software in 1990. Tim then with the help of a data system engineer Robert Cailiau collaberated to request joint funding, the first entry Tim made for this was an encyclopedia. The first publically avaible version of html was on a document called "HTML tags"
